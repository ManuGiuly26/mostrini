# Mostrini

Mini gioco di creature da catturare, da giocare in un pannello mentre Claude lavora. Si apre con `/mostrini`.

## Installazione

Nel prompt di Claude Code da terminale:

```
/plugin install mostrini --marketplace ManuGiuly26/mostrini
```

Da una shell:

```
claude plugin install mostrini --marketplace ManuGiuly26/mostrini
```

Nell'app desktop: clicca + accanto alla casella del prompt, poi Plugins, Add marketplace con `ManuGiuly26/mostrini`, poi Add plugin.
